# Notice

## What this repository is
An independent, educational front-end demo that studies how an existing public Shopify storefront is built and reproduces its design and behaviour. It is **not affiliated with, sponsored by or endorsed by** that store or its owners. Product and brand names, logos, trademarks and photography belong to their respective owners.

## What is deliberately not in this repository
| Not committed | Why | How to get it locally |
|---|---|---|
| Brand fonts (BDSans, Helvetica) and logo | Commercially licensed / trademarked assets | `npm run assets:fetch` or `FETCH_BRAND_ASSETS=1` (opt-in; only if you are authorised) |
| Scraped catalog, product copy, policies, blog articles (`data/`) | Third-party content | generated automatically on first `dev`/`build`, or `npm run data:refresh` |
| Reference screenshots and diffs (`docs/screenshots*`) | Third-party imagery | `npm run visual:capture`, `npm run visual:compare` |
| Raw audit dumps (`docs/data/`) | Third-party content | regenerated by the audit scripts if needed |

Product and editorial images are **hotlinked** from the reference store's CDN at run time, and the homepage embeds the reference's own video player. Nothing is copied into the repository, but hotlinking uses the owner's bandwidth and can break if they change their assets. Do not deploy this demo publicly as-is.

## Responsible use
- Only run the data and asset scripts if you are authorised to use the reference store's content (for example, you are building the replica for that store's owner).
- The scripts request public pages only, throttle themselves and back off on rate limits. Do not remove the throttling.
- The reference store's embedded newsletter form (which posts to its real mailing list) is intentionally **not** reproduced; all forms in this demo are local and send nothing.
- No payments, accounts, orders or inventory are processed.
